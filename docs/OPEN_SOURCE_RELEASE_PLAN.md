# MIT source-code demonstration — separate from this archive

The repository you are reading is a **historical development log**, not the runnable 1 km forest. It contains no original production-game source.

To share implementation ideas, a **separate simplified Three.js/WebGPU demo** was prepared from audited, redistributable pieces. The sample is based on a 96 m scene with procedural trees, terrain and grass; it deliberately does not replicate the original forest's proprietary vegetation assets or image quality.

- Preserve the original project and its third-party licensed assets.
- Release only original/MIT-compatible source, with required notices.
- Use new procedural placeholders when proprietary assets must be excluded.
- Provide separate reproducible install/test instructions and describe recorded performance honestly.
- Publish its code in a **separate repository** after review.

The code demo is not included here and is **not yet published at the time of writing**. Its later publication should be linked from this archive once the repository exists. The private 1 km forest and future fishing game need not be released or licensed under MIT.
