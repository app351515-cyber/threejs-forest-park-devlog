# Acknowledgments and upstream references

This archive documents a forest developed with Three.js/WebGPU through local experiments and study of public technical work. **Studying an approach, adapting source code, and redistributing source code are different things.**

- [SamG-Coder / V2Cuda](https://github.com/SamG-Coder/V2Cuda) — MIT. Private technical investigations used a mist technique adapted from this project. **No V2Cuda source code is redistributed in this documentation repository.**
- [SamG-Coder / ForestSideScroll](https://github.com/SamG-Coder/ForestSideScroll), [MountainRIver](https://github.com/SamG-Coder/MountainRIver), [WaterCuda](https://github.com/SamG-Coder/WaterCuda), [CudaAmazonForest](https://github.com/SamG-Coder/CudaAmazonForest) — related WebGPU forest/water research referenced in the wider set of experiments; this does not imply their code was incorporated in the published documents or simplified demo.
- [cortiz2894 / stylized-components](https://github.com/cortiz2894/stylized-components) — MIT. An archived God Rays experiment studied upstream commit `1cece0a296b29299d1380c34feb5c158b2f04500`.
- [Three.js](https://github.com/mrdoob/three.js) and [meshoptimizer](https://github.com/zeux/meshoptimizer) — open-source dependencies with their own license obligations.

This list is not a substitute for a file-level dependency/asset license audit. Third-party PBR textures, plants and game assets are **not distributed here**. Any separate release that includes upstream source must preserve the required copyright and license notices.
